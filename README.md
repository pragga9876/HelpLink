# 📊 Smart Resource Allocation System

A data-driven platform that transforms scattered community data into actionable tasks and efficiently connects volunteers to real-world needs.

---

## 🚀 Problem

- NGO data is scattered (paper, WhatsApp, spreadsheets)  
- No real-time visibility of urgent needs  
- Volunteers are underutilized  

👉 Result: Delayed response and inefficient resource allocation  

---

## 💡 Solution

A centralized system that:
- Collects and organizes community data  
- Prioritizes needs using a scoring system  
- Generates actionable tasks  
- Matches volunteers based on skills and location  

---

## ⭐ Key Features

- 📥 Centralized Data Collection  
- 🧠 Priority Scoring Engine  
- 📋 Automated Task Generation  
- 🙋 Smart Volunteer Matching  
- 🔥 Micro-Tasking System (USP)  

---

## ⚙️ Tech Stack

- **Frontend:** Next.js, TypeScript, Tailwind CSS  
- **Backend:** Next.js API Routes  
- **Database:** SQLite (Prisma ORM)  
- **Authentication:** NextAuth (JWT-based)  

---

## 🔄 Workflow

1. User submits a problem report  
2. System assigns priority score  
3. Tasks are generated  
4. Volunteers are matched  
5. Tasks are completed and tracked  

---

## ⭐ USP

**Micro-Tasking Approach**
- Breaks large problems into small tasks  
- Enables quick participation  
- Increases volunteer engagement  

---

## 📊 Impact

- Faster response time  
- Efficient resource utilization  
- Increased participation  
- Data-driven decision making  

---
